# APEX DETAILING LAB

Демонстрационный портфолио-проект лендинга студии эстетического и защитного детейлинга. Проект собран на семантическом HTML5, CSS и vanilla JavaScript; серверная заявка обрабатывается одним PHP-файлом без внешних библиотек и сборщика.

> **Важно:** студия, мастера, кейсы, цены и контакты вымышлены и приведены для примера. Это демонстрационный портфолио-проект, не публичная оферта. Не используйте указанные контакты для реальных обращений.

## Состав проекта

- `index.html` — демонстрационный лендинг, OpenGraph, JSON-LD `WebSite`, форма записи, FAQ и модальные окна. Для поисковых роботов включен `noindex, nofollow`.
- `style.css` — адаптивная тема Dark Luxury & Motorsport Tech, включая мобильный bottom-sheet сметы.
- `script.js` — конструктор услуг, матрица расчета, календарь и слоты, форма, сравнение До / После и демо-режим.
- `send.php` — прием JSON-заявки, серверная валидация, повторный расчет по ID и запись защищенного CSV-журнала.
- `favicon.svg` — векторная монограмма A//.
- `404.html` — фирменная страница ошибки для статического хостинга.
- `robots.txt` — закрывает страницы от обхода роботами.
- `data/.htaccess` — запрет доступа к данным через Apache. `data/orders.csv`, `data/.ratelimit` и случайная соль `data/.salt` создаются на рабочем PHP-хостинге и не хранятся в репозитории.
- `images/` — готовые локальные фотографии проекта. Файлы каталога не требуется заменять или скачивать.

## Локальный просмотр

Для верстки можно открыть `index.html` локально. Для проверки реальной отправки формы запустите PHP 8.0+ с корнем проекта в качестве document root:

```powershell
php -S 127.0.0.1:8000
```

Затем откройте `http://127.0.0.1:8000/`. Без согласия на обработку персональных данных отправка и кнопки обмена сметой остаются отключенными. Если PHP-сервер недоступен на localhost или ином домене, интерфейс сообщает об ошибке и не показывает фальшивое подтверждение.

## Публикация

### GitHub Pages

Опубликуйте корень репозитория как статический сайт GitHub Pages. На домене `*.github.io` включен прозрачный демонстрационный режим: форма не отправляет сетевой запрос, расчет выполняется локально, а в подтверждении показывается бейдж «ДЕМО-РЕЖИМ». Файлы `.htaccess` и `send.php` на GitHub Pages не исполняются. Canonical и карточки OpenGraph настроены для:

`https://adik2012.github.io/apex-detailing-lab/`

### PHP-хостинг

Для рабочего размещения используйте Apache с PHP 8.0+ и включенным `mod_authz_core`. Скопируйте все файлы сайта, включая `send.php` и `data/.htaccess`, настройте каталог `data/` так, чтобы PHP мог создавать в нем файлы и выставлять права `0600`, и убедитесь, что `.htaccess` разрешены серверной конфигурацией. Корневой `.htaccess` блокирует `.md`, `.csv`, `.ratelimit`, `.salt` и обращения к `.git`; файл `data/.htaccess` запрещает HTTP-доступ к журналу и служебным файлам.

Обработчик принимает только `POST` с `Content-Type: application/json` и телом до 8 КБ. Он повторно проверяет класс автомобиля, услуги и пакет по списку допустимых значений, дату, слот, мастера, имя, модель, телефон, согласие и промокод. Цены, скидки и часы из клиентского запроса игнорируются: сервер рассчитывает заказ самостоятельно. Расписание и расчет выдачи синхронизированы с часовым поясом `Europe/Moscow`; недоступные слоты отклоняются с HTTP 422. CSV создается при первой заявке в UTF-8 с BOM, с разделителем `;`, защитой от формул CSV и эксклюзивной блокировкой записи. Телефон записывается полностью согласно `LOG_FULL_PHONE = true`. Лимит — пять успешно сохраненных заявок в час на IP; IP хэшируется HMAC-SHA-256 с отдельной случайной солью.

Перед запуском на публичном домене настройте HTTPS, резервное копирование и доступ к логам PHP. Демо-контакты, содержание отзывов, суммы и условия на странице являются примером, а не предложением реальной услуги.

## Расчет комплекса

Источник цен и правил — разделы 2.4 и 3.4 `structure.md`. Таблицы `PRICING` в `script.js` и `$PRICING` в `send.php` содержат одинаковые классы, цены, часы, составы пакетов, пороги и скидки.

1. Без пакета суммируются отдельные услуги. От двух услуг применяется скидка 15%.
2. При активном пакете используется фиксированная цена пакета; дополнительные услуги считаются поверх нее. Скидка 15% может применяться только к двум или более дополнительным услугам.
3. Промокод `APEX10` дает дополнительную скидку 10% от суммы после пакетной цены или комбо-скидки.
4. Подарок предоставляется от итоговой суммы 35 000 ₽ после всех скидок.
5. Продолжительность — сумма часов выбранных услуг; пакетные часы не вводятся отдельными значениями.

| Пакет | Цена class1 / class2 / class3 | Экономия против отдельных услуг | Экономия против ручного комплекса −15% |
|---|---:|---:|---:|
| «Керамическое зеркало» (`pkg-1`) | 54 500 / 65 000 / 80 000 ₽ | 15 000 / 18 000 / 22 000 ₽ | 4 575 / 5 550 / 6 700 ₽ |
| «Броня трассы PPF» (`pkg-2`) | 80 000 / 97 000 / 118 000 ₽ | 22 500 / 27 000 / 33 000 ₽ | 7 125 / 8 400 / 10 350 ₽ |
| «Полная перезагрузка» (`pkg-3`) | 67 500 / 81 000 / 100 000 ₽ | 18 500 / 22 500 / 28 000 ₽ | 5 600 / 6 975 / 8 800 ₽ |

Чистая функция `computeTotals()` используется для клиентского расчета и сравнения цены пакета с ручным комплексом. Контрольные примеры A–E и таблицы цен в `script.js`, `send.php` и `structure.md` должны оставаться синхронными.

## Данные и конфиденциальность

В `localStorage` разрешены только `apex_class`, `apex_services` и `apex_package`. Имя, телефон, модель автомобиля, дата, слот и промокод туда не записываются. На сервере контактные данные записываются только в журнал заявок и предназначены исключительно для обработки записи. Используйте демонстрационный текст политики только как пример: реальный владелец сайта должен подготовить и опубликовать собственные юридические документы и настроить фактические контактные данные до приема заявок.
